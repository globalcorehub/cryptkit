Preguntas Frecuentes y Especificaciones de Seguridad

¿Qué diferencia hay entre claves RSA de 2048 y 4096 bits?

2048 bits es el estándar actual para SSL y SSH; 4096 bits proporciona una seguridad ultra alta para archivado a largo plazo.

¿En qué formato se exportan las claves?

Formato estándar PEM (PKCS#8 para clave privada y SPKI para clave pública), compatible con OpenSSL.

¿Se envían las claves a un servidor?

No. Las claves se generan exclusivamente en su navegador.
