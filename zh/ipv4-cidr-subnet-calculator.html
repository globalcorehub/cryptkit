密码学技术规格与常见问题解答

什么是 CIDR？为什么它取代了传统的 A/B/C 类网络？

CIDR（无类别域间路由，RFC 1519）打破了传统的固定分类边界，支持可变长子网掩码（VLSM），能够按实际所需主机数量精准分配 IP 块，极大节约了 IPv4 宝贵的地址空间。

为什么子网的第一个和最后一个 IP 不能分配给主机？

在任何标准 IPv4 子网中，主机位全为 0 的地址被保留为网络地址（Network ID），主机位全为 1 的地址被保留为子网广播地址（Broadcast）。因此可用主机数计算公式为：2^(32 - 前缀位) - 2。

什么是反掩码（通配符掩码 Wildcard Mask）？

反掩码常用于 Cisco 访问控制列表（ACL）和 OSPF 路由协议中，它是子网掩码的按位求反（即 255.255.255.255 减去当前子网掩码）。
